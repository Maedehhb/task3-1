Interactive Quiz App

A simple and interactive quiz application built with HTML, CSS, and JavaScript.

Features

* Multiple-choice questions about HTML, CSS, and JavaScript
* Interactive answer selection
* Score calculation and final results
* Search questions by keyword
* Filter questions by category
* Save quiz progress using LocalStorage
* Save previous quiz results
* Restore progress after refreshing the page
* Restart the quiz at any time
* Basic validation and error handling
* Responsive design for different screen sizes

Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Event Listeners
* LocalStorage
* JSON

How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in your browser.
4. Start answering the quiz questions.

Project Structure

* index.html — Application structure
* style.css — Styling and responsive layout
* script.js — Quiz logic and interactive features
